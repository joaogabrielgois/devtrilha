# DevTrilha — aprenda construindo

Plataforma de estudos em português para aprender desenvolvimento web, do primeiro código aos conceitos avançados, e usar inteligência artificial com mais autonomia.

**[Acessar o DevTrilha →](https://joaogabrielgois.github.io/devtrilha/)**

## Sobre o projeto

O DevTrilha combina explicações, exemplos, desafios e revisões para transformar estudo em prática. A trilha usa como referência as tecnologias dos projetos **api-predial** e **Luana Carla Doceria**, com C# e ASP.NET Core como uma formação adicional.

O objetivo é desenvolver a capacidade de entender, criar, testar e melhorar projetos próprios.

## Recursos

- **29 aulas em 11 módulos**, com uma sequência sugerida de aprendizado.
- Explicações e exemplos de código em português.
- Desafios com dicas e soluções para comparação.
- Perguntas de revisão com feedback.
- Laboratório para executar **HTML, CSS e JavaScript**.
- Anotações, rascunhos e progresso salvos no navegador.
- Exportação e importação do progresso em JSON.
- Gerador de pedidos de ajuda para usar em ferramentas de IA.
- Três projetos guiados: portfólio, organizador de estudos e sistema completo.
- Layout adaptado a computadores e celulares.

## Como estudar

1. Acesse o site e clique em **Começar minha primeira aula**.
2. Leia o conceito e observe o exemplo.
3. Tente resolver o desafio antes de abrir a solução.
4. Execute o código no laboratório ou no ambiente indicado pela aula.
5. Responda à revisão e registre suas anotações.
6. Confirme a prática para concluir a aula e avance no seu ritmo.

A confirmação de prática é uma **autoavaliação**. O site corrige as perguntas de revisão, mas não avalia automaticamente a solução dos desafios. Concluir a trilha registra seu estudo; dominar as ferramentas exige prática e projetos.

## Tecnologias do site

O próprio DevTrilha foi desenvolvido com:

- **HTML5** para a estrutura;
- **CSS3** para o visual e a responsividade;
- **JavaScript** para a navegação, aulas e interações;
- **localStorage** para persistência no navegador;
- **iframe com sandbox** para o laboratório;
- **GitHub Pages** para hospedagem.

Não há etapa de build nem instalação de dependências para abrir esta versão. React, Node.js, Prisma e C# fazem parte do conteúdo ensinado; não são dependências de execução da plataforma.

## Executar localmente

Clone o repositório:

```bash
git clone https://github.com/joaogabrielgois/devtrilha.git
cd devtrilha
```

Depois, abra o arquivo **index.html** no navegador. Também é possível baixar o repositório em **Code → Download ZIP**, extrair os arquivos e abrir o mesmo arquivo.

Mantenha `index.html`, `styles.css`, `app.js` e `lessons.js` na mesma pasta.

## Progresso e dados

O progresso fica salvo **no navegador utilizado**, sem conta ou sincronização automática entre dispositivos.

- Use **Exportar meu progresso** para guardar uma cópia.
- Use **Importar progresso** para restaurá-la em outro navegador ou dispositivo.
- Limpar os dados do navegador pode apagar o progresso.
- O arquivo local e a versão publicada possuem armazenamentos separados.

## Laboratório e uso de IA

O laboratório executa HTML, CSS e JavaScript. Requisições externas e dependências estão desativadas nesse ambiente. Os exercícios de React, Node.js, SQL e C# são realizados no computador, conforme as instruções de cada aula.

A área de IA **gera textos para copiar e usar em outra ferramenta**. Não há um modelo de IA conectado ao site. O foco é aprender a formular perguntas, revisar respostas e testar o código com autonomia.
